# Milestone 1 acceptance record

Implementation started 31 October 2026. Scope: local **Runs → Finding → Fix → Retest**, including environment management. The approved product decisions remain in `IMPLEMENTATION_PLAN.md`; later Insights and Library expansion has not been folded into this milestone.

## Implemented surface

- React/TypeScript workspace in `journey-workspace/`: project selector, compact ink sidebar, warm canvas, cobalt controls, dense collections and a recording-focused review surface. English, concise copy, keyboard navigation and responsive review.
- SQLite workspace in `journey-engine/workspace-store.mjs`: projects, immutable configuration versions, atomic runs, original model observations plus review overrides, defect Issues and append-only audit events. Existing JSON history is imported idempotently without rewriting the originals.
- `workspace-api.mjs`: project/configuration management, environment readiness, run launch/cancel, finding triage and issue management.
- `workspace-execution.mjs` and the integrated server: serialized run execution, limits, allowed origins and capture policy, source fingerprints, actual request usage, technical capture and durable artifacts. First-time browser state is the default.
- `workspace-fixes.mjs` / `workspace-fix-runtime.mjs`: source-derived acceptance contract, isolated Muse Code rounds, build/test hooks, fresh required-persona retests, review annotations and feedback snapshots, exact-hash approval and explicit PR connection state.
- Real original/condensed video with canonical timestamp mapping. Four timeline tracks: Broken, Experience, Product and Business. Before/after recordings can be paired at reviewer-selected observed moments; unequal journeys are not stretched to fake equivalence.

## Explicit boundaries

- Source/PR provider is unselected. Approval records the exact candidate locally; real draft-PR creation is awaiting connection and has not been claimed or performed.
- Generic framework apps require their own build/start/test commands, dependency availability, approved test session and isolated data. A URL being reachable does not prove it serves the recorded source tree.
- Synthetic persona reactions are annotations, not human sentiment measurements. Numeric signals missing in older history are not backfilled.
- Memory retrieval, analytics calibration, competitor research and aggregate Insights remain P4 onward. Full Library authoring was added later; see `LIBRARY_AUTHORING_STATUS.md`.
- Original files under `sources/`, past recordings, failed attempts and the earlier hackathon demo remain preserved. There is no automatic deletion policy.

## Matching-step comparison update

Fix review now aligns emotional arcs by recorded action order, with exact paired seeks for the two original videos. The matcher uses the completed action leading into each observed screen, not the persona's upcoming intention. Actual controls, safe input/selection values, route visits and preceding action context determine suggestions. Emotion, elapsed time and comment similarity do not. Scrolls, unknown context and conflicting/repeated paths remain reviewable or unmatched.

Review matches supports accept, reject, restore, manual pairing and adjusting a previous decision.
